# Smart Attendance Management

A simple, browser-based attendance management system for colleges and schools.

## Features
- Dashboard with today's attendance and low-attendance alerts (below 75%)
- Add and delete students (roll number, name, class)
- Mark attendance by class and date (Present / Absent toggle, "Mark all present")
- Attendance reports with percentage per student
- Export reports to CSV

## How to Run
1. Download `smart_attendance.html`
2. Open it in any modern browser (Chrome, Edge, Firefox)

No installation or server needed. Data is saved in the browser's local storage.

## Live Demo
GitHub Pages link: `https://<your-username>.github.io/smart-attendance/`

## Tech Stack
- HTML, CSS, JavaScript (no frameworks)
- Browser localStorage for data

- `eventease_ui.html` contains the UI/UX design for the EventEase concept (home, registration, QR ticket, organizer dashboard, design system)
